# Mobishaala Assignment

This is a simple E-commerce website frontend built using **React.js** and **CSS** as part of the Mobishaala Internship Assignment. The design is inspired by [PrintMine.in](https://printmine.in).

## Features

- Homepage with banners and product cards
- Product listing interface
- Responsive design using regular CSS
- Built with React components

## Tech Stack

- React.js
- CSS (no external libraries)
